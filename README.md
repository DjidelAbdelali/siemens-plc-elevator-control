## 📌 Description & Overview

Programmation et simulation d'un système séquentiel de commande d'ascenseur basé sur la logique des automates industriels Siemens (Ladder, Grafcet).

This project is an interactive engineering module built by **DJIDEL Abdelali Rayan** (Systems & Automation Engineer).
